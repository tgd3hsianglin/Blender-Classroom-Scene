# Blender-Classroom-Scene

作品概要

学園祭の教室を舞台に、来場者を迎えるゲーム展示ブースをイメージして制作した3Dシーンです。
Blenderを使用し、モデリングからマテリアル設定、ライティング、レンダリングまで一通り個人で制作しました。

使用ツール・技術:
Blender 5.1/3Dモデリング/マテリアル設定
ライティング（Area Light / Point Light）
レンダリング

制作上の工夫:
教室内の机、黒板、窓、展示ブース、装飾などを配置し、学園祭らしい雰囲気を表現しました。
また、光源の配置やマテリアルの調整を通じて、シーン全体が自然に見えるよう工夫しました。

今後の展望:
今後は、本作品をWebVR/WebXRコンテンツに活用することを検討しています。VRヘッドセットやPCブラウザから教室内を自由に探索できる、インタラクティブなゲームの開発を目指しています。
